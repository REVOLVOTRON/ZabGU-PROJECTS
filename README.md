# ZabGU — учебные проекты

Сборник заданий по программированию. В репозитории есть графический калькулятор на Python и PyQt6.

## Калькулятор
Каталог Calculator_zad1/ содержит интерфейс и вычислительную логику: gui.py, calc_logic.py и Calculator.py.

## Запуск
Установите PyQt6 командой pip install PyQt6 и запустите python Calculator_zad1/Calculator.py.

Используйте только для учебных выражений: вычислительная логика должна быть проверена перед вводом недоверенного текста.

## Статус
Учебный архив. Остальные задания добавляются по мере выполнения.
